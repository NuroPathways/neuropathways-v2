# Replit Prompt: Clean Up NeuroPathways UI Design Without Changing App Functionality

I want you to clean up the NeuroPathways app UI and make it look more polished, organized, and professional.

Do not remove current features.

Do not change how the app works.

Do not rebuild the app from scratch.

This is a design cleanup, spacing cleanup, typography cleanup, card cleanup, and navigation consistency update.

The current app has the right features, but the visual design looks too large, blocky, and inconsistent. Some text is unnecessarily large. Some cards are too tall. Some blue circular/pill labels have too much text inside them. The goals section looks odd. The AI chat looks blocky. The home page should feel cleaner and more useful.

Keep the current features, but make the UI feel like a polished mobile-first healthcare SaaS app.

---

## 1. Overall Design Goal

Make the app feel:

- cleaner
- calmer
- more organized
- less bulky
- less oversized
- more professional
- easier to scan
- more mobile-friendly
- more consistent across pages

The app should not feel like huge blocks of text in large cards.

The app should feel like a modern support app for parents and clinicians.

## 3. Create a Consistent Design System

Add or clean up shared design tokens.

Use consistent:

- font sizes
- card padding
- border radius
- shadows
- badge styles
- button sizes
- spacing
- section headings
- page widths

Recommended font scale:

- small label: 12px
- body: 14px–16px
- card title: 18px–20px
- section title: 22px–26px
- page title: 28px–34px max

Avoid oversized text unless it is the main page title.

Recommended spacing:

- card padding: 20px–24px desktop
- card padding: 16px–20px mobile
- section spacing: 24px–32px
- card gap: 16px–20px
- button height: 44px–52px

Do not use huge empty spacing inside cards.

---

## 4. Fix the Large Blue Circular / Bubble Labels

The current blue bubbles with long text inside look awkward and take up too much space.

Replace large source bubbles with smaller, clean source badges.

Instead of a big blue oval that says:

**Source: Uploaded plan · not yet reviewed by a clinician**

Use a small inline badge:

`Uploaded plan · not clinician-reviewed`

or:

`Starter support`

or:

`Clinician reviewed`

Badge style:

- small pill
- light background
- short text
- max one line
- no huge circles
- no giant blue blobs
- no oversized badge padding

If the full source text is needed, show it in a tooltip, expandable detail, or smaller line under the card.

The home page should remain focused on daily utility.

Keep:

**Support for John**

**I Need Help Now**

button near the top.

## 6. Make Tasks and Activities Cleaner

The task/activity cards currently have too much text visible at once.

Redesign task and activity cards to be easier to scan.

Each task card should show:

- task title
- related behavior
- estimated time
- one short instruction
- small source badge
- action buttons

Example card:

**Practice: Complete one small step**  
Task Refusal · 5 min  
Try one small, low-pressure practice step before offering a break.  
Badge: `Starter support`

Buttons:

- Done
- Didn’t get a chance
- We struggled

Then add an expandable link:

**Show details**

When expanded, show:

- why this helps
- practice this skill
- reinforcement idea
- source details

Do not show all details by default.

This will make the home page much cleaner.

For task cards, use compact segmented actions:

## 8. Better Goals Page Design

The Goals page currently looks odd and disconnected.

Redesign the Goals page so it feels like a clean goal management page, not a set of oversized empty blocks.

The Goals page should show:

## Active Goals

Each goal card should include:

- goal title
- related behavior
- source
- status
- last check-in
- next suggested practice
- quick check-in buttons

Goal card format:

**Complete one small step**  
Related behavior: Task Refusal  
Source: Uploaded plan · not clinician-reviewed  
Last check-in: Going well · 10/6/2026

Quick check-in:

- Going well
- Needs support
- Not sure

Then show:

**Suggested home activity:** Practice one small step before a break.

Button:

**Add to Today’s Tasks**

This connects goals back to the home page.

---

## 9. Goals Should Feed the Home Page

Goals should not dominate the home page as a big goal card.

Instead, goals should power the tasks and activities shown on the home page.

Example:

Goal:

**Complete one small step**

Home page task:

**Start with one small step before offering a break.**

Goal:

**Move to a calm space**

Home page activity:

**Practice moving to a calm space when calm.**

Goal:

**Stay near caregiver**

Home page activity:

**Practice stopping at a boundary.**

So the home page should show practical tasks and activities, while the Goals page manages the goal records.
