## PROJECT OBJECTIVE

I want to significantly improve the visual design and user experience of the existing NeuroPathways application.

Use the attached screen recording:

"Screen Recording 2026-10-17 at 7.46.07 PM.mov"

1. The independent parent account.
2. The clinician-connected parent account.

Review both experiences before making changes.

Currently, the application has the functionality I want, but the presentation feels:

- Too blocky
- Too crowded
- Too text-heavy
- Too many rectangular containers
- Too little breathing room
- Visually repetitive
- Overwhelming during stressful moments
- Too similar to a clinical dashboard or documentation system

I want the application to feel like a polished, modern behavioral-health support tool.

The design should be:

- Calm
- Spacious
- Professional
- Modern
- Welcoming
- Intuitive
- Easy to scan
- Accessible
- Appropriate for stressed caregivers
- Visually engaging without looking childish

Use established design principles from Apple Human Interface Guidelines, Calm, Headspace, Apple Health, and Nielsen Norman Group.

Do not directly copy their designs.

Use them as inspiration for information hierarchy, whitespace, typography, and mobile usability.

## Improve Spacing

Recommended starting values:

Mobile horizontal margins:
20px

Section spacing:
28–36px

Related element spacing:
12–16px

Card padding:
16–20px

List row spacing:
8–12px

Use these as guidelines.

Do not apply excessive spacing everywhere.

The goal is visual balance.

## Reduce the Number of Cards

Not every section needs a container.

Use:

### Open Sections

For headings and short descriptions.

### Lightly Separated Groups

For lists and related information.

### Floating Cards

For important actions and focused content.

Examples:

- Help Now
- Current activity
- Current support step
- Featured activity
- Active routine

Do not place cards inside cards unnecessarily.

## Typography

Suggested hierarchy:

Page title:
26px

Section title:
20px

Card title:
17px

Body:
15–16px

Supporting text:
13–14px

Keep normal text clearly readable.

Fix insufficient contrast.

Create a consistent icon style.

Use meaningful icons for:

- Support
- Practice
- Goals
- Documents
- Routines
- Communication
- Safety
- History
- Settings

Do not add icons beside every line.

## Floating Design

Introduce subtle shadows and elevation.

Do not make every section appear elevated.

Use visual depth sparingly.
