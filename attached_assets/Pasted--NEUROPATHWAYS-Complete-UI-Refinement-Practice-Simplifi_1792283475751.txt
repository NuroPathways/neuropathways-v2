# NEUROPATHWAYS
# Complete UI Refinement, Practice Simplification, and Clinician-Assigned Goals & Activities

## PRIMARY OBJECTIVE

I want you to continue improving the existing NeuroPathways application by implementing the following changes directly into the working codebase.

This is a full implementation request, not a request for suggestions or another design proposal.

The major goals are:

1. Fix unreadable white text and other contrast problems throughout the application.
2. Completely remove Learn Why as a separate navigation feature.
3. Simplify and better organize the parent Practice experience.
4. Allow clinicians to create, edit, assign, and publish goals for individual clients.
5. Allow clinicians to create or assign specific activities to individual clients.
6. Introduce an "Assigned by Your Care Team" section within the parent's Practice experience.
7. Clearly distinguish clinician-assigned goals from family-created goals.
8. Connect clinician assignments, parent activities, goals, and feedback.
9. Allow clinicians to see relevant parent-recorded observations.
10. Fix poorly formatted goal titles.
11. Improve document scanning error messages and retry functionality.
12. Preserve all existing account types and the unified parent experience.

The finished application should be simple, organized, accessible, and easy for parents and clinicians to use.

## NON-NEGOTIABLE REQUIREMENTS

- Do not change the existing NeuroPathways color scheme.
- Do not create another parent portal.
- Do not rebuild the entire application.
- Do not remove existing working features.
- Do not delete existing data.
- Preserve the clinician dashboard.
- Preserve independent parent accounts.
- Preserve clinician-connected parent accounts.
- Preserve legacy username/access-code family accounts.
- Preserve the family-scoped authentication bridge.
- Preserve individual self-managed client accounts.
- Preserve current document uploads and scanning.
- Preserve existing goals, activities, and history.
- Keep the design simple, spacious, and mobile-friendly.
- Do not introduce unnecessary tabs or navigation layers.

Use the October 17 evening screen recording as a visual reference.

Inspect the current Replit code before modifying anything.

Create a recovery checkpoint before implementation.

The current Replit application may contain newer functionality than the GitHub main branch. Do not overwrite those changes.

# PHASE 1 — FIX UI READABILITY AND TEXT CONTRAST

## Current Problem

In the latest recording, several headings have white or nearly white text against very light backgrounds.

This makes the text extremely difficult to read.

Examples include:

- Today's Support
- Practice
- Child names in page headers
- Supporting descriptions under page titles
- Some navigation and section headings

I want this fixed throughout the application.

## Required Changes

Inspect the existing header components, typography styles, gradients, and inherited CSS classes.

Pay attention to:

- text-white
- text-white/50
- text-white/60
- text-white/70
- opacity classes
- inherited foreground colors
- background gradients
- active navigation text
- dark-mode and light-mode styles

Use the application's existing dark text color on light backgrounds.

Only use white text when the background is sufficiently dark.

Do not solve this problem by introducing an entirely new color palette.

Do not simply add dark boxes behind every heading.

Correct the actual color and contrast rules.

## Pages to Review

Check:

- Home
- Practice
- Goals & Milestones
- Document Center
- Help Now
- My Routines
- Saved Activities
- Child Profiles
- Clinician Dashboard
- Client Details
- Intervention Plans
- Progress Reports
- AI Chat
- Settings

Verify normal text meets a minimum 4.5:1 contrast ratio and qualifying large text meets at least 3:1.

The current colors should remain recognizable.

## Desired Result

All headings, descriptions, buttons, and labels should be immediately readable without needing to zoom in or highlight the text.
