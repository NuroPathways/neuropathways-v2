# Replit Prompt: Revert Dashboard UI Back to Left Sidebar Layout While Keeping All Features

I want to improve the NeuroPathways app UI by reverting the main dashboard layout back to the older design style that used a **left-side sidebar menu**.

Do not remove, rename, or break any current features. This is mainly a UI/layout change.

The current app has improved features, but I liked the older dashboard structure better because the left sidebar made the app feel more organized, more professional, and easier to navigate.

The goal is to keep all current functionality but redesign the dashboard navigation around a clean left sidebar.

---

## 1. Restore the Left Sidebar Dashboard Layout

Bring back the older dashboard format with a persistent menu on the left side.

The sidebar should be visible on desktop/tablet layouts.

The sidebar should include clear navigation items based on the user’s role.

Use a calm, modern healthcare SaaS design.

The sidebar should feel polished, simple, and professional.

Do not make the app feel cluttered.

The sidebar should change based on the logged-in user role.

## 5. Support Now / I Need Help Now Placement

The **I Need Help Now** button should remain highly visible.

Even with the sidebar layout, it should still be easy to access in one tap/click.

Place it:

- near the top of the main dashboard
- also as a sidebar item under **Support Now**
- optionally as a floating button on mobile

Do not bury the crisis/support feature inside multiple menus.

If a user has multiple children/clients, clicking I Need Help Now must ask:

**Who do you need support for?**

Then:

**What do you need help with right now?**

Do not randomly select a child or behavior.
