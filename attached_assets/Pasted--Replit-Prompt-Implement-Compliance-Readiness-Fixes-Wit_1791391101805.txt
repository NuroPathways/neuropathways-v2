## 2. Implement Account-Holder Age / Authority Gate

The review found that parent and clinician registration do not currently enforce account-holder age or authority.

Add a real signup gate.

During signup, ask:

**Who is creating this account?**

Options:

- Parent / Guardian
- Clinician
- Adult Client
- Teen Client with Parent/Guardian Permission

Add required confirmation checkbox:

**I confirm I am 18 or older, or I have parent/guardian permission to use this account.**

For parent accounts, add required checkbox:

**I confirm I am the parent, guardian, or authorized caregiver for any child profile I create.**

If the user indicates they are under 13, block self-signup and show:

**A parent or guardian must create this account. NeuroPathways does not allow children under 13 to create their own accounts.**

Store these fields:

- account_holder_type
- account_holder_age_group
- adult_or_guardian_confirmed
- parent_guardian_authority_confirmed
- child_profile_created_by_adult
- consent_timestamp
- consent_version

Do not prevent parents from creating child profiles.

Do not require long verification during MVP.

But do add the actual gate and stored confirmation.

## 7. Remove Sensitive AI Chat Excerpt Logging

The review found that the legacy client AI chat records the first 80 characters of the user’s message as an engagement topic.

Change this.

Do not store raw AI chat excerpts, partial health text, child names, or sensitive user-entered text as analytics/engagement topics.

Replace stored AI engagement text with safer structured metadata, such as:

- ai_chat_used
- topic_category if safely classified
- selected_child_id
- timestamp
- source_context_type
- no_raw_message = true

If a topic summary is needed, generate a non-sensitive category such as:

- behavior_support_question
- document_question
- goal_question
- crisis_support_question
- general_support_question

Do not store `msg.slice(0, 80)` or any raw excerpt.

Update privacy/details pages to match the actual logging behavior.
