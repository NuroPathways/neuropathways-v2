## 7. Full Starter Behavior Library

The parent version should include the full starter behavior library.

Starter behaviors:

1. **Elopement / Running Away**
2. **Self-Injury**
3. **Aggression**
4. **Meltdowns**
5. **Task Refusal**
6. **Transition Difficulty**
7. **Other / Custom Behavior**

Parents should be able to add one behavior during setup and add supplemental behaviors immediately or later.

Each behavior card should show a short explanation, not a long support plan on the landing page.

Example:

**Elopement / Running Away**  
Leaving the area, bolting, or moving toward unsafe places.

**Self-Injury**  
Head hitting, biting, scratching, or other unsafe self-directed behavior.

**Aggression**  
Hitting, kicking, biting, throwing, or unsafe physical behavior.

**Meltdowns**  
Crying, screaming, shutting down, or becoming overwhelmed.

**Task Refusal**  
Refusing homework, chores, hygiene, or other non-preferred tasks.

**Transition Difficulty**  
Struggling to stop one activity and move to the next.

## 12. Starter Support vs Uploaded-Plan Support

Do not let starter support override uploaded plan information.

## 13. Document Upload Should Upgrade Behavior Support

AI should:

- identify behaviors in the document
- identify goals in the document
- match document behaviors to existing starter behaviors
- merge duplicate information
- add new behaviors if found
- replace generic strategies with document-based strategies
- preserve source references
- update Support Now cards
- update goal blocks
- update AI chat knowledge base

If the uploaded document supports a behavior already active, upgrade that behavior from starter support to uploaded-plan support.

If the document includes a new behavior, add it to the Behavior Support Library as:

**Found in Uploaded Plan**
